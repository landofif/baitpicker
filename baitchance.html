What affects bait chance
  • Luck sets the rarity that is rolled first (see the Luck page). The bait is checked after that.
  • The bait's own likelihood (the Lik % on the wiki, e.g. Leopard Frog 80%) is the chance the bait takes effect once the rarity is rolled.
  • Bait effectiveness (reels) multiplies that likelihood: 80% x 1.08 = 86.4%. Capped at 100%.
  • The bait only helps for the fish it targets, in water it can be used in. The target fish set the rarities it can produce.
  • If the rolled rarity has no target fish, the bait falls to the next lower rarity that has one. A rolled rarity below every target fish gets a normal fish (no upgrade).
  • So a rolled legendary or mythical with an epic-only lure becomes epic when the bait hits: more luck makes the lure turn higher rolls into epic, it never upgrades above the pool.
